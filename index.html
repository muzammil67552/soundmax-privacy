Privacy Policy

SoundMax Audio Booster • Effective Date: November 2026

Summary: SoundMax operates entirely locally inside your browser using the HTML5 Web Audio API. We do not collect, store, sell, or transmit any audio streams, browsing activity, or personal identifiers.

1. Real-Time Audio Processing (No Recording)

SoundMax captures active tab audio using the browser's native chrome.tabCapture API and processes it directly on your local hardware via the Web Audio API (AudioContext, GainNode, and BiquadFilterNode).

  • Audio Never Leaves Your Device: Audio streams are amplified entirely in temporary system memory and piped straight to your audio output device. No audio data is ever recorded, stored on disk, or streamed externally.
  • No Eavesdropping: Microphones, webcams, and hardware inputs are never requested, accessed, or monitored.

2. Chrome Web Store Permissions Justification

SoundMax adheres strictly to Google Chrome Web Store's Least Privilege and Single Purpose policies:

  • tabCapture: Captures the active tab's audio output stream to route it through our high-performance Web Audio gain and equalizer node graph.
  • offscreen: Required by Chrome Manifest V3 architecture to host the background Web Audio DSP processing engine without degrading tab performance.
  • tabs: Detects which tabs are actively emitting sound (audible: true) so you can switch between media tabs with one click.
  • storage: Saves your volume slider levels, preset preferences, and license state locally on your machine via chrome.storage.local.
  • activeTab: Grants temporary interaction with the active tab when clicking the SoundMax toolbar icon.
